# Efficient Privacy-Preserving Blueprints for Threshold Comparison

This repository contains anonymized code for a submission to Financial Cryptography and Data Security 2026.

This repo uses [mise-en-place](https://mise.jdx.dev/) to run scripts.

To generate the proofs move into an appropriate `benchmarks` subdirectory and run the following commands:

-   `mise download_ptau`
-   `mise compile`
-   `mise gen_ver_key`
-   `mise gen_input`
-   `mise gen_witness`
-   `mise prove`
-   `mise get_size`
